# Measure Availability and Technical Validation / 测量可用性与技术核验

This folder contains the rendered technical-validation report and its Quarto source. The report summarizes valid sample sizes, descriptive statistics, behavioral effect sizes, questionnaire reliability, behavioral split-half reliability, and numerical checks for the released measures.

本文件夹保存技术核验报告的HTML成品及Quarto源文件，内容包括各测量的有效样本量、描述统计、行为指标效应量、问卷信度、行为任务拆半信度和派生数据数值核验。

## Files / 文件说明

| File or folder | Description |
|---|---|
| `Technical_Validation.html` | Rendered report for viewing and sharing. |
| `Technical_Validation.qmd` | Quarto source for the report. Its tables read the generated, identifier-free results rather than manually re-entered statistics. |
| `Technical_Validation_files/` | Companion resources and generated identifier-free CSV tables used by the rendered HTML. |

## Updating the report / 更新报告

The `.qmd` tables depend on the identifier-free statistics generated by the current statistics and split-half blocks in `analysis.Rmd`. After regenerating those results, render `Technical_Validation.qmd` with Quarto. The HTML can be viewed without Quarto, but updating it requires Quarto and the generated result files.

qmd表格依赖 `analysis.Rmd` 当前统计及拆半信度代码块生成的无身份标识结果。重新生成这些结果后，再用Quarto渲染 `Technical_Validation.qmd`。查看现有HTML不需要Quarto；更新报告则需要Quarto和对应结果文件。
